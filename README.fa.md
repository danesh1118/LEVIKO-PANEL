# 🦖 نصب‌کننده TrexBridge

### استقرار خودکار پنل TrexBridge روی Cloudflare Workers

نصب‌کننده تحت وب یک‌کلیکه — بدون ترمینال و بدون تنظیم دستی Binding.

---

## ✨ امکانات

| قابلیت | توضیح |
|--------|--------|
| 🚀 **نصب یک‌کلیکه** | فقط با یک API Token |
| 🗄️ **دیتابیس خودکار** | ساخت و اتصال D1 با نام متغیر `DB` |
| 🔗 **استقرار Worker** | آپلود `Panel.js` و Deploy |
| 🌐 **دو زبانه** | فارسی / English |
| 🔐 **پروکسی اختیاری** | برای دور زدن محدودیت CORS مرورگر |

---

## 🚀 شروع سریع

1. فایل `index.html` را در مرورگر باز کن (یا روی GitHub Pages بگذار)
2. روی **ساخت توکن در Cloudflare** بزن — دسترسی‌ها از قبل انتخاب شده‌اند
3. توکن را پیست کن
4. نام Worker و دیتابیس را تنظیم کن (یا پیش‌فرض بگذار)
5. **استقرار** را بزن
6. لینک پنل را باز کن → در اولین ورود رمز پنل را خودت می‌سازی

**مسیر پنل بعد از نصب:**  
`https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/panel`

---

## 📁 ساختار پروژه

```
trexbridge-installer/
├── index.html           # رابط نصب‌کننده
├── installer-proxy.js   # پروکسی CORS (اختیاری)
└── README.md
```

---

## 🔑 دسترسی‌های لازم توکن

- **Account** — Read  
- **Account Analytics** — Read  
- **D1** — Edit  
- **Workers Scripts** — Edit  

دکمه ساخت توکن داخل اینستالر همین دسترسی‌ها را از قبل انتخاب می‌کند.

---

## 🔒 درباره پروکسی

مرورگر به خاطر CORS نمی‌تواند مستقیم به `api.cloudflare.com` درخواست بزند.

- فیلد پروکسی را **خالی** بگذار → اینستالر خودش تلاش می‌کند  
- یا `installer-proxy.js` را روی یک Worker خودت Deploy کن و آدرسش را در تنظیمات پیشرفته وارد کن

---

## ⚙️ پیش‌فرض‌ها

|--------|--------|
| نام Worker | `trexbridge` |
| دیتابیس D1 | `trexbridge-db` |
| نام Binding | `DB` (الزامی برای Panel.js) |
| مسیر پنل | `/panel` |

## 📦 میزبانی اینستالر

### GitHub Pages

1. این پوشه را در یک ریپو بگذار  
2. Settings → Pages → از شاخه `main` Deploy کن  
3. آدرس: `https://YOUR_USER.github.io/YOUR_REPO/`

### لوکال

فقط `index.html` را با مرورگر باز کن.
